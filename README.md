# student-academic-decision-system - Group ICE Task
Each person owns one Java class.
Push your file directly to this repo root.

## File Ownership
| # | File | Owner | Covers |
|---|------|-------|--------|
| 1 | `StudentProfile.java` | Person 1 | steps 1-3 (data capture & display) |
| 2 | `AgeCategoryAnalyzer.java` | Person 2 | Requirements 1 & 6 (age group, special category) |
| 3 | `AcademicResultEvaluator.java` | Person 3 | Requirements 2 & 4, Exercise 1 (mark validation, grading) | 
| 4 | `EligibilityChecker.java` | Person 4 | Requirements 3 & 5, Step 9 (attendance, exam eligibility, nested decisions) |
| 5 | `StudentServiceCalculator.java` | Person 5 | Exercise 2, 3, 4 (fees, admission, emergency support) | 
| 6 | `ServiceMenuSystem.java` | Person 6 | Requirements 7, Steps 10-11, Exercise 5, `main()` - integration |

## How to Run
```
javac *.java
java ServiceMenuSystem
```
## Before You Push
1. `git pull` first to get everyone else's latest files.
2. Make sure your file compiles alongside the others.
3. Commit with a clear message, example `"Add AcademicResultEvaluator - Req 2 & 4"`.
4. Push
